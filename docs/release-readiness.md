# 광고 없는 첫 출시 준비

기준: 2026-10-26 KST. 콘솔 조회와 로컬 소스 점검 결과이며 검수 승인이나 실기기 완료를 뜻하지 않는다.

## 현재 상태

- 콘솔 최신 번들: 20261023-6, deploymentId `01a16735-b322-7203-aef6-bc38eea183a6`, 업종별 프리셋 추가, CREATED. isTested는 실제 기기 검증 완료 근거로 사용하지 않는다.
- 앱 정보 BEFORE_FIRST_REVIEW, 최초 등록 미완료, 라이브 배포 없음.
- 콘솔에 국문명·아이콘은 존재한다. 영문명·설명·상세 설명·카테고리·키워드·스크린샷은 비어 있다.

## 이번 보완

- 앱 시작 시 User.getAnonymousKey로 현재 사용자 식별키를 조회해 기록과 별도 Storage 키에 저장한다. 앱 세션에서 한 번 실행하며 StrictMode의 중복 실행을 합친다.
- 미지원·조회 실패·저장 실패 시 자동 재시도와 식별키 로그 없이 기존 로컬 기록 이용을 유지한다. 다음 앱 시작에서 다시 시도한다.
- 식별키 저장은 계정별 기록 분리·서버 백업·기기 간 동기화를 제공하지 않는다. 기존 기록 키·데이터 형식은 유지한다.

### 설정 접근과 클립보드 권한 안내

- 준비된 앱의 모든 일반 화면(홈·유형·프리셋·작성·목록·상세·설정)에 플랫폼 톱니바퀴를 노출한다. 초기 로딩·저장 데이터 오류 화면은 기록 정리를 안전하게 제공할 수 없어 기존 상태 처리를 유지한다.
- 설정 진입 직전 화면을 기억하고 뒤로가기로 복귀한다. 작성 초안·저장 스냅샷·기존 recordId를 유지해 설정 방문만으로 입력이나 dirty 상태가 없어지지 않게 했다. 삭제·이탈 확인창이나 저장 작업 중에는 설정 이동을 막는다.
- 설정에서 Clipboard.setText.getPermission/openPermissionDialog로 쓰기 권한을 확인·요청한다. 실제 클립보드 쓰기나 읽기는 하지 않는다. 허용·거절·조회 실패 안내를 구분한다.
- 사용자 기기의 ‘텍스트 붙여넣기’ 토글과 SDK 권한의 정확한 대응·설정 경로는 실기기 미확인이다. 토글 상태를 허용으로 단정하지 않고, 문제가 있으면 해당 설정을 켜고 재시도하도록 안내한다. 권한 기본값을 강제하는 설정은 추가하지 않았다.
- 공식 근거: https://developers-apps-in-toss.toss.im/documentation/common/permission/clipboard . 설치 SDK의 메서드는 TypeScript 빌드 통과로 확인했다.
- 테스트 48개·lint·타입·Vite·ait 빌드 통과. 신규 설정 UI와 내비게이션·권한 팝업의 실기기 통과는 아직 미확인이다. 각 화면 진입→설정→뒤로가기, 미저장 작성 내용 유지와 이탈 안내, 허용·거절·기허용 시 권한 안내를 확인한다.

### 추가 수정·아카이브 판단

- 버튼 요청 때 본문을 ‘현재 복사 권한을 확인하고 있어요’로 바꾸는 처리를 제거했다. 기존 본문은 유지하고 결과 도착 시에만 갱신한다. 진행 표시는 버튼 안에만 둔다. lint·tsc·diff 검사 통과. 이 마지막 문구 수정은 아직 빌드·업로드하지 않았다.
- record-pins-and-cleanup: apply 기준 10개 중 9개 완료, 4.2 미완료. strict 검사는 통과하지만 계획 artifact 완료는 구현·기기 검증 전체 완료를 의미하지 않는다.
- 4.2의 고정 재실행 유지·미고정 삭제 후 고정 보존은 사용자 확인 기록이 있다. 취소·뒤로가기·키보드·빈 목록·광고 슬롯 상세 결과와 정확한 환경 기록은 부족하므로 전체 완료로 바꾸지 않는다.
