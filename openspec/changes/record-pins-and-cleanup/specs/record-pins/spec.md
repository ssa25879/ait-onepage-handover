# 기록 고정

## Purpose

자주 참고하는 인수인계 기록을 사용자가 고정하고 전체 목록의 앞에서 다시 찾도록 한다. 저장된 기존 내용과 홈의 최근 기록 의미를 보존하면서 고정 상태를 기록 수정과 앱 재실행 이후에도 유지한다.

## ADDED Requirements

### Requirement: PIN-01 고정과 해제

시스템 SHALL 홈 최근 기록·전체 목록 카드와 상세 제목의 우측 상단 핀 버튼으로 고정·해제하게 하고 현재 상태를 구분해 표시한다. 신규 기록은 미고정이며 고정 개수에 별도 제한을 두지 않는다. 고정 변경은 본문·업무 날짜·작성 및 수정 시각을 바꾸지 않는다.

#### Scenario: 고정 상태 전환
- **WHEN** 미고정 기록의 고정을 선택하고 저장이 성공한다
- **THEN** 목록과 상세의 고정 표시가 갱신되며 다시 해제할 수 있다

#### Scenario: 재실행과 수정
- **WHEN** 고정한 기록을 수정·저장한 뒤 앱을 재실행한다
- **THEN** 수정 내용과 고정 상태가 모두 유지된다

#### Scenario: 저장 실패와 중복 요청
- **WHEN** 고정 저장이 실패하거나 다른 기록 변경이 진행 중이다
- **THEN** 성공으로 표시하지 않고 기존 기록과 고정 상태를 보존하며 중복 쓰기를 실행하지 않는다

### Requirement: PIN-02 고정 우선 목록과 최근 기록

시스템 SHALL 전체 목록에서 고정 그룹을 먼저 표시하고 각 그룹 안에서 업무 날짜 내림차순, 같은 날짜는 수정 시각 내림차순으로 정렬한다. 홈 최근 최대 3건은 고정 여부와 무관하게 기존 날짜·수정 시각 순서를 유지한다. 날짜·수정 시각이 같은 동률 순서는 보장하지 않는다.

#### Scenario: 오래된 고정 기록
- **WHEN** 오래된 고정 기록과 최신 미고정 기록이 함께 있다
- **THEN** 전체 목록은 고정 기록을 앞에 표시하고 홈 최근 목록은 날짜순을 유지한다

#### Scenario: 해제 후 위치
- **WHEN** 고정 기록을 해제한다
- **THEN** 미고정 그룹의 날짜·수정 시각 순서에 맞는 위치로 이동한다

### Requirement: PIN-03 기존 저장 데이터 호환과 보호

시스템 SHALL 고정 정보가 없는 기존 기록을 미고정으로 읽고 내용을 보존한다. 고정 정보가 유효하지 않거나 저장소가 손상·미지원·읽기 실패 상태이면 자동 초기화와 고정·삭제·저장 쓰기를 차단한다. 기존 개별 삭제 확인은 고정 기록에도 적용한다.

#### Scenario: 기존 기록 읽기
- **WHEN** 고정 정보가 없는 기존 기록을 로드한다
- **THEN** 데이터 손실과 자동 쓰기 없이 미고정으로 표시한다

#### Scenario: 잘못된 고정 정보
- **WHEN** 저장된 고정 정보가 boolean 이외의 값이다
- **THEN** 오류와 재시도를 안내하고 원본을 덮어쓰지 않는다

#### Scenario: 고정 기록 개별 삭제
- **WHEN** 고정 기록의 개별 삭제를 확인하고 저장이 성공한다
- **THEN** 그 기록만 삭제되며 다른 고정·미고정 기록은 유지된다
