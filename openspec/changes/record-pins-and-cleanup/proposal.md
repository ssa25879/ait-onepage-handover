# Proposal

## Why

자주 참고하는 인수인계가 날짜순 목록에 묻히고 오래된 기록을 하나씩 삭제해야 한다. 중요한 기록을 고정해 보존하면서 나머지 기록을 한 번에 정리할 수 있게 한다.

## What Changes

- 기록 목록·상세에서 핀 고정과 해제를 제공하고 전체 목록은 고정 기록부터 표시한다.
- 홈의 플랫폼 내비게이션 톱니바퀴에서 진입하는 설정 화면에 ‘고정하지 않은 기록 삭제’를 추가한다. 삭제 대상 수와 보존 수를 안내하고 확인 후 삭제한다.
- 기존 기록은 고정하지 않은 상태로 읽고, 고정 상태를 저장·재실행·수정 이후에도 유지한다.
- 홈 최근 3건은 기존 날짜·수정 시각 순서를 유지한다. 고정 개수는 제한하지 않는다.
- 범위 제외: 고정 기록까지 일괄 삭제, 기록 재사용·사용자 템플릿, 서버 동기화·복구함, 기타 설정 기능.

## Capabilities

### New Capabilities

- `record-pins`: 기록 고정·해제, 목록 우선 표시, 저장 호환성 및 고정 상태 유지.
- `record-cleanup`: 설정 진입과 고정하지 않은 기록의 확인 후 일괄 삭제.

### Modified Capabilities

- 없음. 정식 `openspec/specs/`는 비어 있다. 활성 `handover-mvp`의 `handover-records` REC-02는 전체 목록을 날짜순으로 정의하므로 이 변경 적용 시 고정 우선 정책과 조정해야 한다.

## Impact

- 대상: src/types/handover.ts, src/lib/storage.ts, src/lib/handover.ts, src/App.tsx, 기록 목록·상세·홈 화면, 신규 설정 화면과 관련 스타일, tests/.
- 현재 v1 저장 키·envelope를 유지하고 선택적인 고정 필드를 추가한다. 새 의존성·권한·서버는 필요 없다.
- 기존 MVP 작업은 미완료로 유지한다. 적용 전 REC-02 충돌을 명시적으로 조정하고 두 change의 archive 순서를 확인한다.
