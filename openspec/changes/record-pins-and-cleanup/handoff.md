# 기록 고정·정리 구현 인계

## 2026-10-26 최신 동작과 명세 동기화

최신 실기기 확인: 20261026-14 안내 후 사용자가 ‘전부 확인했어. 실기기로’라고 보고했다. 본 change의 남은 4.2와 최근 설정·권한 안내·광고 배치를 사용자 확인 완료로 기록하고 tasks를 10/10으로 갱신했다. 아래 과거 미완료·확인 대기 설명은 이 결과로 대체한다. 정확한 Android·OS 빌드·토스 앱 버전과 항목별 캡처는 미기록이다. 테스트 광고 확인은 운영 광고 노출 검증을 대체하지 않으며, iOS·손상 데이터 주입·MVP 출시 준비는 별도다. 명세 동기화를 마쳤으므로 본 change는 아카이브 가능한 상태로 판단하되 이번 확인 기록에서는 archive 명령을 실행하지 않았다.

이 절은 아래의 과거 홈 전용 설정 진입 설명보다 우선한다. 정상 로드된 모든 일반 화면에서 설정 톱니바퀴를 표시하고 설정의 뒤로가기는 진입 직전 화면으로 복귀한다. 작성 입력·미저장 상태는 보존한다. 기록 정리를 최상단에, 권한 안내를 아래에 배치한다. 권한 조회 중 본문은 기존 결과를 유지하고 진행 표시는 버튼에만 둔다.

record-cleanup의 CLEAN-01과 design을 위 동작으로 조정하고 record-cleanup·record-pins를 openspec/specs에 동기화했다. handover-mvp REC-02의 고정 우선 목록·홈 날짜순 규칙과 PIN-02가 일치한다. 전체 OpenSpec strict 검사 4건과 테스트 48개가 통과했다. 4.2의 미기록 실기기 검증은 완료 처리하지 않았고 archive는 진행하지 않았다. 본 동기화는 심사 승인·공개나 모든 실기기 항목 통과를 의미하지 않는다.

## 구현 상태

- 고정 필드 누락은 미고정으로 읽는다. 선택적 isPinned는 boolean만 허용하며 자동 변환·초기화하지 않는다.
- 목록·상세에서 고정·해제할 수 있다. 전체 목록은 고정 우선, 홈 최근 최대 3건은 기존 날짜순이다.
- 고정 변경은 본문·날짜·작성/수정 시각을 바꾸지 않으며 수정 저장 후에도 유지된다.
- 홈 플랫폼 내비게이션의 설정 톱니바퀴에서 전체·보존·삭제 수를 확인한다. ‘고정하지 않은 기록 삭제’는 고정 기록을 보존한다.
- 대상 0건은 비활성화하며 삭제 확인에 범위·보존 수·복구 불가를 안내한다. 취소·뒤로가기는 확인창만 닫는다.
- 확인창의 배경은 inert, 저장·삭제·고정은 공통 쓰기 잠금을 사용한다. 성공한 저장 결과만 확정한다.
- 고정 기록도 상세의 개별 삭제는 가능하다. 전체 초기화·서버 백업·복구함은 제공하지 않는다.
