# 내용 복사

## Purpose

사용자가 작성한 인수인계를 외부 메신저에 직접 붙여 넣을 수 있는 일관된 텍스트로 제공한다. 복사 성공과 저장 성공을 구별하고 복사 실패가 기록이나 작성 중 내용을 변경하지 않도록 한다.

## ADDED Requirements

### Requirement: COPY-01 일관된 텍스트 출력 (F-06)
시스템 SHALL 제목·날짜·업무 유형·완료 업무·진행 중 업무·전달사항 순서로 텍스트를 만든다. 빈 본문 섹션은 생략한다. 각 본문의 비어 있지 않은 줄을 원래 순서대로 `- ` 접두사와 함께 출력하고 줄 양끝 공백과 빈 줄은 생략한다.

#### Scenario: T-09 세 본문 복사 형식
- **WHEN** 카페·음식점, 2026-10-22, 완료 업무에 청소 완료, 진행 중에 재고 확인, 전달사항에 예약 확인을 입력한다
- **THEN** 결과는 다음 문자열과 일치한다

```text
[인계한장 - 업무 인수인계]

날짜: 2026-10-22
업무 유형: 카페·음식점

■ 완료 업무
- 청소 완료

■ 진행 중 업무
- 재고 확인

■ 전달사항
- 예약 확인
```

#### Scenario: T-10 빈 섹션과 여러 줄
- **WHEN** 완료 업무에 두 줄을 쓰고 다른 본문은 공백만 입력한다
- **THEN** 완료 업무 두 줄만 각 줄에 접두사를 붙이고 진행 중·전달사항 제목은 생략한다

### Requirement: COPY-02 복사와 저장의 독립성 (F-06 F-08)
시스템 SHALL 편집 중 내용과 상세 기록을 복사하게 한다. 편집 화면 복사는 현재 입력을 사용하며 저장하지 않는다. 날짜·본문 검증을 통과하지 못한 빈 문서는 복사하지 않는다. 성공은 클립보드 쓰기 완료 후에만 안내하고 실패 시 입력과 기록을 보존한다.

#### Scenario: 미저장 편집 내용 복사
- **WHEN** 기존 기록을 수정한 뒤 저장하지 않고 복사한다
- **THEN** 편집 중 내용이 복사되고 원본 기록은 바뀌지 않으며 미저장 상태와 저장 별도 안내가 유지된다

#### Scenario: T-12 클립보드 거절
- **WHEN** 클립보드 쓰기가 실패하거나 현재 환경에서 지원되지 않는다
- **THEN** 실패 또는 미지원 안내를 표시하고 성공으로 표시하지 않으며 본문·기록에 영향이 없다

#### Scenario: 빈 본문 복사
- **WHEN** 모든 본문이 공백이거나 날짜가 유효하지 않다
- **THEN** 유효성 오류를 안내하고 클립보드를 변경하지 않는다
