# 고정하지 않은 기록 정리

## Purpose

사용자가 앱 내 설정에서 보존할 고정 기록과 삭제할 나머지 기록을 구분하여 오래된 인수인계를 한 번에 정리하도록 한다. 삭제 범위와 복구 불가를 미리 안내하고 취소·실패 시에는 기존 데이터를 보호한다.

## Requirements

### Requirement: CLEAN-01 설정 진입과 삭제 범위 안내

시스템 SHALL 정상 로드된 홈·유형 선택·프리셋·작성·목록·상세·설정 화면의 플랫폼 내비게이션 톱니바퀴로 설정에 접근하게 한다. 기록 정리를 권한 안내보다 먼저 표시하고 전체·보존할 고정·삭제할 미고정 기록 수를 구분한다. 작업 이름은 미고정 기록만 삭제한다는 의미를 전달한다. 설정의 뒤로가기는 진입 직전 화면으로 복귀하며 작성 입력과 미저장 상태를 보존한다. 변경 작업이나 확인창이 진행 중이면 설정 이동을 차단한다.

#### Scenario: 설정 열기
- **WHEN** 고정 2건과 미고정 3건이 있는 사용자가 설정을 연다
- **THEN** 전체 5건·보존 2건·삭제 예정 3건을 확인할 수 있다

#### Scenario: 삭제 대상 없음
- **WHEN** 기록이 없거나 모두 고정되어 있다
- **THEN** 삭제를 실행할 수 없고 삭제 대상이 없음을 안내한다

#### Scenario: 작성 중 설정 방문
- **WHEN** 저장하지 않은 작성 내용이 있는 사용자가 설정을 열고 플랫폼 또는 시스템 뒤로가기를 누른다
- **THEN** 원래 작성 화면으로 돌아가며 입력·미저장 상태를 유지한다

#### Scenario: 설정 표시 순서
- **WHEN** 사용자가 설정을 연다
- **THEN** 기록 정리가 첫 섹션이고 권한 안내가 그 아래에 표시된다

### Requirement: CLEAN-02 확인 후 미고정 기록 삭제

시스템 SHALL 실행 전 삭제 수·보존 수·복구 불가를 알리고 명시적 확인과 취소를 제공한다. 확인 시 미고정 기록만 삭제하고 고정 기록의 내용·식별자·시각·상태를 유지한다. 모든 기록을 삭제하는 별도 기능은 제공하지 않는다.

#### Scenario: 혼합 기록 정리
- **WHEN** 고정 2건과 미고정 3건에서 삭제를 확인하고 저장이 성공한다
- **THEN** 미고정 3건만 사라지고 고정 2건은 재실행 후에도 유지된다

#### Scenario: 고정 기록이 없는 경우
- **WHEN** 모든 기록이 미고정인 상태에서 삭제를 확인하고 저장이 성공한다
- **THEN** 정상 빈 기록 상태가 되고 새 기록 작성이 가능하다

#### Scenario: 취소와 뒤로가기
- **WHEN** 확인창에서 취소하거나 플랫폼·시스템 뒤로가기를 누른다
- **THEN** 확인창을 닫고 저장소와 기록을 변경하지 않는다

### Requirement: CLEAN-03 성공 확정과 실패 보호

시스템 SHALL 저장 성공 후에만 삭제 결과를 확정하고 홈·목록·설정에 반영한다. 변경 중 중복 조작을 차단하고 확인한 대상 수와 실행 결과가 어긋나지 않게 한다. 읽기 실패·손상·미지원 상태에서는 삭제를 차단한다.

#### Scenario: 쓰기 실패
- **WHEN** 삭제 확인 후 저장소 쓰기가 실패한다
- **THEN** 실패를 안내하고 모든 원본 기록·고정 상태·카운트를 유지하며 재시도를 허용한다

#### Scenario: 쓰기 중 재조작
- **WHEN** 삭제 저장이 진행 중인데 고정 변경·삭제·저장 또는 연속 확인을 요청한다
- **THEN** 중복 쓰기와 기록 유실 없이 한 번의 결과만 확정한다

#### Scenario: 손상 데이터
- **WHEN** 저장소를 안전하게 읽을 수 없다
- **THEN** 초기화로 우회하지 않고 삭제를 차단하며 원본과 재시도 경로를 유지한다
